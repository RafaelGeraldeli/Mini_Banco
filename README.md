# Mini_Banco

Mini Banco realizado nas aulas do Senac.

## 🚀 Funcionalidades
- Cadastro de clientes e contas.
- Registro de transações bancárias (depósito, saque, transferência).
- Geração de relatórios associados ao titular da conta.

## 🛠️ Tecnologias Utilizadas
Liste as ferramentas e linguagens utilizadas:
- Java
- Visual Studio Code
